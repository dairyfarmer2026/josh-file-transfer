PERSONAL WORKSPACE CONNECTION

Josh File Transfer

A personal-use connection between Josh McDonald's Google Drive and his workspace.

What this connection does

Josh File Transfer uses rclone to list, download, upload, and verify files in the owner's Google Drive. It supports the owner's project-file storage and transfers. It is not offered as a public service.

Why Google Drive access is requested

The connection needs permission to find existing project folders and transfer files selected by the owner. Google's Drive permission can also allow changing or deleting files; these operations are performed only when authorized by the owner. Background access allows routine transfers without a new sign-in for every job.

Your control

The owner chooses the files and destinations and can revoke access in Google Account connections. This public information site does not display Google Drive contents, accept uploads, or collect sign-in credentials.

Support

This connection is maintained by its owner. For a technical issue, use the project support page. Do not post credentials or private file contents.
